# 골프연습

스윙을 한 번씩 촬영하고 분석하는 앱. 현재 PWA 촬영·재생 및 촬영 후 자동 자세 검출 진단을 구현했다. 스윙 지표 계산과 Supabase 연동은 미구현이다. 확정 요구사항과 상태는 [progress.md](progress.md)를 참조한다.

## 개발

Node 22.12 이상, npm 11 사용. 루트에서 실행한다. Windows PowerShell에서는 `npm.cmd`를 사용한다.

```sh
npm install
npm run dev
npm run typecheck
npm test
npm run build
```

`apps/pwa`는 Ionic React + Vite 앱이다. 향후 앱인토스·하이브리드는 별도 앱으로 추가한다. 공유 도메인은 실제 분석 계약 확정 후 분리한다.

카메라는 localhost 또는 HTTPS 환경이 필요하다. iPhone의 실제 검증은 HTTPS 제공 환경을 준비한 뒤 진행한다. 개발 서버는 LAN 인터페이스에도 열리므로 신뢰할 수 있는 개발 네트워크에서 사용한다.

현재 영상은 서버에 전송하지 않으며 메모리에만 유지된다. 촬영 종료 후 모델·WASM을 외부에서 다운로드해 기기에서 5fps 자세 검출 진단을 실행한다. 검출 프레임 수·가시성·처리 시간을 표시하며 골프 정확도 점수가 아니다. 검증 기준·출처·라이선스는 [자세 검증 문서](docs/pose-validation.md)를 참조한다.

실험용 머리 이동 비율과 2D 몸통 기울기 변화를 표시한다. 기본은 전체 촬영 구간이며 시작·끝 시간을 수동 지정하면 구간 내 첫 분석 샘플 기준으로 다시 계산한다. 미터 이동량·실제 척추각·실력 점수가 아니다. 자동 스윙 구간 분석과 정확도는 미검증이다.

이메일 가입·로그인·비밀번호 복구와 결과 저장·최근 20건 조회 코드를 준비했다. 실제 연결은 [Supabase 개발 설정](docs/supabase-setup.md)을 따른다. 설정이 없으면 로그인·저장만 비활성화된다. 마이그레이션·실제 인증·RLS는 아직 통합 검증하지 않았다.

정식 스윙 지표·서비스 워커·오프라인은 아직 제공하지 않는다. 배포 환경과 운영 절차는 미정이다.
