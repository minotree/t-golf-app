# PWA 테스트 배포·기기 검증

갱신: 2026-10-19. 공개 출시 완료가 아닌 사용자 테스트용 배포다. 최신 상태·주소는 progress.md를 확인한다.

테스트 주소: https://t-golf-app.vercel.app

배포 READY 및 위 주소에서 PC 브라우저 6건 통과를 확인했다. 실기기·실제 사용자 데이터 저장은 별도 검증 대상이다.

## Vercel 설정

- 새 프로젝트 `t-golf-app`, 저장소 루트 기준. `vercel.json`으로 `npm ci` → `npm run build`, 산출물 `apps/pwa/dist`를 지정한다.
- Node 22.12 이상. npm 잠금 파일을 유지한다.
- Production·Preview 환경에 `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`만 설정한다. 둘은 클라이언트 공개 설정이며 서버 비밀 키·OIDC 토큰을 빌드 변수로 전달하지 않는다.
- `.env.local`, `.vercel`, 의존성·테스트 결과·로컬 산출물은 업로드·커밋에서 제외한다. Vercel 로그인은 로컬 인증 프로필을 사용한다.
- 배포 명령: 저장소 루트에서 `npx vercel --prod`. 배포는 별도 승인 시에만 실행한다. 이번 테스트 배포는 사용자 지시로 승인되었다. 향후 커밋·푸시는 별도 Git 승인 규칙을 따른다.
- GitHub 저장소는 연결되어 있지만 `vercel.json`의 `git.deploymentEnabled: false`로 Git 자동 배포를 비활성화한다. 커밋·푸시 승인과 배포 승인을 분리하며, 승인 후 CLI로 수동 배포한다. 근거: https://vercel.com/docs/project-configuration/git-configuration (확인: 2026-10-19).

## 설치·캐시·업데이트

- 빌드 스크립트가 180·192·512 PNG 아이콘, 웹 앱 manifest, 해시 버전 서비스 워커와 제3자 고지를 생성한다. 아이콘은 원래 SVG와 같은 자체 제작 깃발 도형을 코드로 그린다.
- 앱 화면·정적 JS/CSS·아이콘만 캐시한다. 영상·샘플·인증 응답·DB 응답·모델·외부 서버 응답은 서비스 워커 캐시에 넣지 않는다.
- 처음 온라인에서 앱을 열어 캐시 준비 후 오프라인 화면 재열기 가능. 모델 초기 다운로드·서버 인증·저장은 온라인 필요. 완전한 오프라인 분석·저장 대기 큐는 제공하지 않는다.
- 새 버전은 대기 상태로 안내한다. 영상 촬영·분석 결과가 남은 화면에서는 업데이트 버튼을 막고, 다음 촬영으로 돌아간 후 사용자가 적용한다. 새로고침하면 메모리 영상·미저장 결과는 사라진다.
- `sw.js`는 Vercel에서 no-cache/no-store로 제공한다. HTML은 네트워크 우선·연결 실패 시 캐시로 열고 정적 해시 파일은 캐시를 사용한다. 브라우저 module 요청의 Vary 헤더 차이로 생기는 캐시 누락을 방지했다.

## 배포 후 Supabase에서 할 일

Supabase Authentication → URL Configuration에서 실제 배포 origin을 Site URL·허용 Redirect URLs에 추가한다. 기존 localhost 개발 주소는 테스트에 필요하면 유지한다. 이 콘솔 설정은 이번 작업에서 자동 변경하지 않았다.

기존 계정의 이메일·비밀번호 로그인과 가입 확인·비밀번호 복구 링크 동작은 별개로 확인한다. 이메일 링크가 localhost로 열리면 URL Configuration·이메일 템플릿의 redirect 설정을 점검한다. DB 마이그레이션·두 사용자 RLS는 별도 검증 대상이다.

## PC 검증

```powershell
npm.cmd test
npm.cmd run typecheck
npm.cmd run build
npm.cmd run test:e2e --workspace @golf/pwa
```

E2E는 설치된 Chrome을 사용한다. `PWA_BROWSER=msedge`로 Edge를 선택할 수 있지만 해당 환경을 별도 검증한다. 테스트는 localhost 4173을 사용한다. 실제 모델 다운로드 테스트에는 네트워크가 필요하다. Playwright는 Apache-2.0 개발 의존성이다.

카메라 OS 가상 장치가 1초 안에 종료되는 환경을 발견했다. UI 흐름 검사는 canvas 합성 영상과 실제 MediaRecorder·디코더를 사용하며 실제 카메라 성공으로 보고하지 않는다. 사용자 계정은 사용하지 않고 로그인 응답을 모의 처리한다. 별도 테스트는 실제 모델·WASM 초기화 후 빈 이미지 추론을 실행한다.

## 사용자 iPhone 13 Pro 테스트

1. 배포 HTTPS 주소를 Safari에서 열고, 공유 → 홈 화면에 추가한다.
2. Safari 탭과 홈 화면 앱에서 각각 카메라 허용·거부·재시도, 세로·가로, 촬영 종료·30초 종료·백그라운드 복귀를 확인한다. 혼자 촬영 기능 배포 후 전면/후면 전환, 바닥 거치 구도, 즉시/5초/10초 대기와 취소도 확인한다.
3. 빈 스윙부터 촬영하고 전신·조명·촬영 각도별 검출과 처리 시간을 확인한다. 정식 측정 정확도 검증은 pose-validation.md를 따른다.
4. 수동 구간·템포·추정 어깨축 표시와 측정 불가 사유를 확인한다. 템포·어깨 추정은 현재 화면 확인용이며 DB 저장은 2D 머리·몸통 결과만 포함한다.
5. 로그인 → 선택 구간 결과 저장 → 기록 상세 조회, 로그아웃·계정 분리·오프라인 안내를 확인한다.
6. 새 배포 후 업데이트 대기 안내·영상 보존 안내·적용 흐름을 확인한다.

문제 보고에는 기기·iOS/Safari 버전·발생 단계·화면 오류 문구를 기록한다. 비밀번호·키·개인 영상은 공유하지 않는다.

## 이용 고지

빌드의 `third-party-notices.txt`는 설치된 production 의존성의 라이선스·고지와 MediaPipe Apache-2.0 원문을 포함한다. 원본 SDK·모델은 수정하지 않는다. 고지 생성 스크립트와 잠금 파일을 함께 유지한다. 최초 모델 다운로드는 외부 서버 연결을 동반한다.

이 배포는 골프 지표의 정확도·공식 점수·비거리 예측을 보장하지 않는다. 운영 공개 출시 전 데이터 보관·탈퇴·개인정보처리방침과 실제 기기·계정 권한 검증을 마쳐야 한다.
