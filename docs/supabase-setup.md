# Supabase 개발 환경 연결

작성: 2026-10-19. 이번 작업에서는 원격 DB·인증 설정 변경이나 이메일 발송을 실행하지 않았다.

## 설정

1. 개발용 Supabase 프로젝트를 준비한다. 운영 DB와 구분한다. 무료 구간을 우선하며 유료 도입은 승인 후 진행한다.
2. `apps/pwa/.env.example`을 `apps/pwa/.env.local`로 복사하고 프로젝트 URL과 **publishable key**(`sb_publishable_` 접두어)를 로컬에서 입력한다. 이 파일은 Git 제외 대상이다. 값은 채팅에 보내지 않는다.
3. 서버 비밀 키·service_role은 절대 넣지 않는다. 현재 클라이언트는 publishable key만 허용하며 구형 anon JWT 키는 받지 않는다. 미설정 시 로그인·저장만 비활성화하고 촬영·분석은 유지한다.
4. 준비된 마이그레이션 `supabase/migrations/202610190001_swing_results.sql`을 개발 DB에 적용한다. 아직 실행하지 않았다. 운영 DB에는 별도 승인 없이 적용하지 않는다.
5. Supabase Auth 이메일·비밀번호 제공자, 이메일 확인, 비밀번호 정책을 설정한다. UI 최소 길이는 8자이며 서버 정책이 우선한다. Site URL과 허용 Redirect URLs에 실제 개발·배포 주소를 등록한다. 앱의 이메일 링크 목적지는 현재 origin/path다.
6. 환경 변경 후 `npm.cmd run dev`를 재시작한다. iPhone 테스트는 HTTPS에서 진행한다.

키·프로젝트 미설정 상태를 테스트 성공으로 해석하지 않는다. 실제 URL·키·DB가 준비되어야 통합 검증할 수 있다.

## 데이터와 권한

- `swing_results`: 소유자, 분석 ID, 클럽·촬영 방향, 모델·계산 버전, 영상 길이·선택 구간·기준 시각·샘플 수, 2개 실험 지표 또는 측정 불가 사유.
- 머리 이동은 몸통 길이에 대한 비율(0.2 = 20%), 몸통 변화는 deg다. 값 없음은 null과 사유로 보존한다.
- 영상·원시 관절 샘플·이메일·비밀번호는 결과 행에 포함하지 않는다. 비밀번호는 Supabase Auth에 인증 목적으로 전달하며 결과 테이블이나 앱 로그에 보관하지 않는다.
- RLS: authenticated 사용자는 본인 결과만 SELECT·INSERT 가능. anon은 테이블 접근 불가. UPDATE·DELETE는 허용하지 않는다.
- `(user_id, analysis_id, start_seconds, end_seconds)` UNIQUE로 동일 분석·구간 재저장을 막는다. 재시도 중 중복 오류가 나면 본인 동일 분석·구간 존재를 확인해 저장 완료로 처리한다. 페이지를 새로 열어 다시 분석하면 별도 분석 ID다.
- 저장을 누른 비회원은 로그인 폼으로 이동하고 현재 페이지에서 로그인되면 동일 결과를 저장한다. 구간 변경·재촬영으로 해당 결과 화면이 사라지면 저장 대기는 취소된다. 이미 서버로 전송된 저장 요청은 화면 전환으로 롤백되지 않는다.
- 가입 확인·비밀번호 복구 이메일 링크로 페이지를 새로 열면 메모리 영상과 미저장 분석은 사라진다. 현재 구현은 미저장 결과의 페이지 간 복구를 제공하지 않는다.
- 최근 기록은 로그인 후 버튼으로 본인 20건을 조회한다. 기록 상세·삭제·페이지네이션은 후속 작업이다.

## 통합 검증 — 미실행

- A·B 두 개발 계정과 비회원으로 접근한다. 비회원 SELECT·INSERT 차단, A의 B 데이터 SELECT·INSERT·UPDATE·DELETE 차단을 DB/API에서 확인한다.
- 본인 저장·조회, 값 범위 CHECK, 동일 구간 동시 저장·네트워크 응답 유실 후 재시도 UNIQUE를 확인한다.
- 가입 확인·로그인 실패·로그아웃·세션 만료·복구 링크·새 비밀번호 갱신과 Redirect URL을 검증한다.
- 비회원 결과 → 로그인 → 이어서 저장, 저장 대기 취소, 계정 전환 시 기록 목록 초기화를 확인한다.
- 네트워크 전송에 영상·샘플·비밀 키가 포함되지 않는지 확인한다.
- 실제 적용 후 Supabase 생성 타입으로 테이블 계약을 고정하는 작업과 DB 권한 회귀 테스트를 추가한다.

## 공식 근거·의존성

2026-10-19 확인. Supabase 공식 JS SDK v2를 사용하며 정확한 설치 버전은 package-lock.json에 고정되어 있다. 설치 패키지 라이선스는 MIT이며 공개 배포 시 적용 고지를 보존한다. 기존 의존성에 인증·DB 클라이언트가 없어 공식 SDK를 추가했다. 브라우저 대응·번들 크기는 배포 빌드 및 실기기로 계속 검증한다.
